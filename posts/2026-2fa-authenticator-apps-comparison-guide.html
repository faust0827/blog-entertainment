출처: Google Authenticator · Microsoft Authenticator · Authy · Aegis · 2FAS

앱별 상세 분석

1. Google Authenticator

가장 널리 사용되는 2FA 앱으로, 대부분의 서비스에서 기본 지원합니다. 설정이 간단하고 QR 코드 스캔만으로 계정을 추가할 수 있습니다. Google 계정으로 클라우드 백업이 가능하지만, 백업 데이터는 암호화되지 않은 상태로 Google 서버에 저장된다는 점이 보안 우려 사항입니다. 다중 기기 동기화가 제한적입니다.

2. Microsoft Authenticator

Microsoft 계정 및 Azure AD 환경에서 강력한 통합을 제공합니다. 비밀번호 없는 로그인(Passwordless)을 지원하며, Microsoft 계정으로 클라우드 백업이 가능합니다. iOS와 Android 모두 지원하며, 생체 인증 잠금을 제공합니다. Microsoft 생태계를 사용하는 경우 최적의 선택입니다.

3. Authy

여러 기기에서 동일한 계정을 동기화할 수 있어 기기 분실 시 복구가 쉽습니다. 데스크톱 앱을 지원하여 PC에서도 인증 코드를 확인할 수 있습니다. 백업 데이터는 암호화되어 저장됩니다. 다만 Twilio 계정이 필요하며, 서비스 종료 가능성에 대한 우려가 있습니다.

4. Aegis Authenticator

Android 전용 오픈소스 2FA 앱으로, 보안과 개인정보 보호에 중점을 둡니다. 백업 파일은 사용자 지정 비밀번호로 암호화되며, 클라우드에 자동 업로드되지 않습니다. 아이콘 커스터마이징, 검색, 분류 기능을 제공합니다. iOS를 사용하는 경우 선택할 수 없습니다.

5. 2FAS

iOS와 Android를 모두 지원하는 오픈소스 2FA 앱입니다. iCloud 또는 Google Drive로 암호화 백업을 저장할 수 있습니다. 브라우저 확장 프로그램을 통해 PC에서 인증 코드를 확인할 수 있는 기능을 제공합니다. 인터페이스가 깔끔하고 사용이 편리합니다.

선택 가이드

  • 간편함 우선: Google Authenticator — 설정이 가장 쉽고 호환성이 높음
  • Microsoft 생태계: Microsoft Authenticator — Azure AD, 비밀번호 없는 로그인 지원
  • 다중 기기 동기화: Authy — 데스크톱 포함 여러 기기에서 동기화
  • 보안/오픈소스 (Android): Aegis — 로컬 암호화 백업, 클라우드 미사용
  • 보안/오픈소스 (iOS+Android): 2FAS — 크로스 플랫폼 오픈소스, 브라우저 확장 지원

2FA 사용 시 주의사항

  • 백업 코드를 안전한 곳에 보관하세요. 기기 분실 시 계정 복구에 필수입니다.
  • 클라우드 동기화를 사용하는 경우 계정 보안(강력한 비밀번호, 2FA)을 강화하세요.
  • SIM 스와핑 공격에 취약한 SMS 인증보다 앱 기반 2FA를 권장합니다.
  • 여러 2FA 앱에 동일 계정을 등록하면 백업 효과가 있습니다.
