핵심 요약: 브라우저 확장 프로그램은 편리하지만, 과도한 권한을 가진 확장은 개인정보 유출, 광고 삽입, 계정 탈취의 경로가 될 수 있습니다. 확장 설치 전 권한 확인, 출처 검증, 정기적인 정리가 필수입니다.

확장 프로그램의 위험성

브라우저 확장은 웹 페이지의 내용을 읽고, 수정하고, 네트워크 요청을 가로챌 수 있는 강력한 권한을 가집니다. 악성 확장은 검색 결과를 조작하거나, 로그인 정보를 탈취하거나, 사용자 모르게 광고를 삽입할 수 있습니다.

문제는 확장이 "무료"로 제공되면서 사용자 데이터를 수집하거나 광고 수익을 올리는 비즈니스 모델을 가진 경우가 많다는 점입니다. 겉으로는 유용해 보이지만, 내부적으로는 사용자 행동을 추적하고 판매할 수 있습니다.

안전한 확장 선택 기준

1. 출처 확인

공식 웹 스토어(Chrome Web Store, Firefox Add-ons)에서 설치하되, 개발자 정보와 리뷰를 확인해야 합니다. "Featured" 또는 "Recommended" 배지가 있는 확장이 더 안전합니다. 외부 사이트에서 .crx 파일을 직접 다운로드하는 것은 피해야 합니다.

2. 권한 최소화

확장 설치 시 요청하는 권한을 반드시 확인하세요. "모든 웹사이트의 데이터 읽기 및 변경" 권한이 필요한 확장은 그 이유가 명확해야 합니다. 광고 차단기는 모든 사이트 권한이 필요하지만, 메모 앱이 모든 사이트 권한을 요청한다면 의심해야 합니다.

3. 사용자 수와 리뷰

사용자 수가 많고 리뷰가 좋은 확장이 일반적으로 더 안전합니다. 다만 최근에 인기를 얻은 확장은 검증이 부족할 수 있으므로, 설치 후 권한 사용을 모니터링해야 합니다.

4. 업데이트 주기

정기적으로 업데이트되는 확장이 더 안전합니다. 오랫동안 업데이트되지 않은 확장은 보안 취약점이 방치될 수 있습니다. 또한 확장이 매각되거나 개발자가 변경되면 악성 코드가 삽입될 수 있으므로, 업데이트 후 권한 변경 여부를 확인해야 합니다.

해설·분석

브라우저 확장 보안에서 가장 중요한 것은 **"필요한 것만 설치"** 원칙입니다. 확장이 많을수록 공격 표면이 넓어지고, 성능도 저하됩니다. "나중에 쓸 수도 있으니" 설치해 두는 습관은 보안 위험을 키웁니다.

또한 확장의 권한은 설치 시점뿐 아니라 업데이트 시에도 변경될 수 있습니다. 확장 업데이트 후 새로운 권한을 요청하는 경우가 있으므로, 업데이트 알림을 무시하지 말고 확인해야 합니다.

특히 금융, 이메일, 클라우드 계정을 사용하는 브라우저에는 최소한의 확장만 설치하는 것이 안전합니다. 광고 차단기와 비밀번호 관리자 정도로 제한하고, 나머지는 별도 브라우저 프로필에서 사용하는 것이 좋습니다.

자주 묻는 질문

Q. 광고 차단기는 안전한가요?
uBlock Origin, AdGuard 등 오픈소스 광고 차단기는 상대적으로 안전합니다. 다만 일부 광고 차단기는 "허용 가능한 광고" 프로그램에 참여하여 특정 광고를 허용할 수 있으므로, 설정을 확인해야 합니다.

Q. 확장이 내 비밀번호를 읽을 수 있나요?
권한에 따라 가능합니다. "모든 웹사이트의 데이터 읽기" 권한이 있는 확장은 입력 필드의 값을 읽을 수 있습니다. 비밀번호 입력 시 확장이 활성화되어 있으면 주의가 필요합니다.

Q. 시크릿 모드에서 확장이 동작하나요?
기본적으로 시크릿 모드에서는 확장이 비활성화됩니다. 설정에서 "시크릿 모드에서 허용"을 켜지 않는 한 안전합니다.

Q. 출처는 어디서 확인하나요?
Chrome Web Store와 Firefox Add-ons의 공식 페이지, 그리고 KISA의 보안 안내에서 확인할 수 있습니다.
