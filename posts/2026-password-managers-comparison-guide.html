앱별 상세 분석

1. Bitwarden

오픈소스 기반의 클라우드 동기화 비밀번호 관리자로, 무료 플랜에서도 무제한 항목 저장과 다기기 동기화를 제공합니다. 엔드투엔드 암호화와 제로 지식 아키텍처를 채택하여 서버가 마스터 비밀번호를 알 수 없습니다. 브라우저 확장, 모바일 앱, 데스크톱 앱을 모두 지원하며, 자체 호스팅도 가능합니다. TOTP 저장은 Premium에서만 가능합니다.

2. KeePassXC

로컬 파일 기반의 오픈소스 비밀번호 관리자로, 데이터베이스 파일(.kdbx)을 사용자가 직접 관리합니다. 클라우드 동기화가 없어 보안성이 높지만, 여러 기기에서 사용하려면 Dropbox, Google Drive 등 클라우드 드라이브에 파일을 직접 저장해야 합니다. TOTP 생성, 브라우저 자동 입력, YubiKey 등 하드웨어 키 지원을 무료로 제공합니다.

3. Proton Pass

Proton Mail, Proton VPN을 만든 Proton AG의 비밀번호 관리자로, 엔드투엔드 암호화와 제로 지식을 지원합니다. 이메일 별칭(alias) 생성 기능이 내장되어 스팸 방지에 유리합니다. 무료 플랜에서도 무제한 항목과 다기기 동기화를 제공하며, 오픈소스 클라이언트를 제공합니다.

4. Google 비밀번호 관리자

Chrome 브라우저와 Android에 내장된 비밀번호 관리자로, Google 계정으로 자동 동기화됩니다. 별도 설치 없이 바로 사용할 수 있어 편리하지만, Chrome/Android 생태계에 종속됩니다. 제로 지식이 아니므로 Google 서버가 데이터에 접근할 수 있다는 점이 보안상 단점입니다. 패스키(passkey) 지원이 강점입니다.

5. Apple 키체인 (iCloud 키체인)

macOS와 iOS에 내장된 비밀번호 관리자로, iCloud로 자동 동기화됩니다. Safari와 앱에서 자동 입력을 지원하며, 패스키와 2FA 코드 저장(일부)도 가능합니다. Apple 생태계 사용자에게 가장 편리하지만, Windows나 Android에서는 사용할 수 없습니다.

선택 가이드

  • 범용 추천: Bitwarden — 무료로 다기기 동기화, 오픈소스, 자체 호스팅 가능
  • 최고 보안/로컬: KeePassXC — 데이터를 사용자가 직접 관리, 클라우드 의존 없음
  • 이메일 별칭 필요: Proton Pass — 별칭 생성으로 개인정보 보호 강화
  • Chrome/Android 사용자: Google 비밀번호 관리자 — 별도 설치 불필요, 패스키 지원
  • Apple 생태계: Apple 키체인 — macOS/iOS 네이티브 통합, 자동 입력

비밀번호 관리자 사용 시 주의사항

  • 마스터 비밀번호는 길고 고유하게 설정하고, 다른 곳에 재사용하지 마세요.
  • 마스터 비밀번호 분실 시 복구가 불가능한 경우가 많으므로 백업 방법을 마련하세요.
  • 2FA를 비밀번호 관리자 계정에 반드시 활성화하세요.
  • 정기적으로 유출된 비밀번호를 점검(비밀번호 관리자의 유출 확인 기능 활용)하세요.
  • 공용 컴퓨터에서는 비밀번호 관리자 자동 로그인을 비활성화하세요.
