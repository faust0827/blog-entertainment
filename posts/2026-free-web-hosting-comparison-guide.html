서비스별 상세 분석

1. GitHub Pages

GitHub 저장소에서 직접 웹사이트를 호스팅합니다. Jekyll을 기본 지원하며, 정적 사이트 생성기에 최적화되어 있습니다. 100GB/월 대역폭과 무제한 빌드를 제공합니다. 서버리스 함수는 지원하지 않지만, GitHub Actions로 CI/CD를 구성할 수 있습니다. 개발자에게 가장 친숙한 선택입니다.

2. Netlify

정적 사이트와 서버리스 함수를 함께 호스팅할 수 있습니다. 드래그 앤 드롭으로 배포할 수 있으며, 양식 처리, 인증, 서버리스 함수 등 부가 기능이 풍부합니다. 300분/월 빌드 시간과 100GB/월 대역폭을 무료로 제공합니다. 프리뷰 배포와 브랜치별 배포가 가능하여 팀 협업에 적합합니다.

3. Vercel

Next.js 개발사가 만든 호스팅 플랫폼으로, Next.js에 최적화되어 있습니다. 6000분/월 빌드 시간과 100GB/월 대역폭을 제공합니다. Edge Network를 통해 전 세계에서 빠른 응답 속도를 보장합니다. 서버리스 함수와 Edge Functions를 지원합니다. React/Next.js 프로젝트에 가장 적합합니다.

4. Cloudflare Pages

무제한 대역폭을 제공하는 유일한 서비스입니다. Cloudflare의 글로벌 CDN을 통해 빠른 전송 속도를 보장합니다. Workers를 통해 서버리스 함수를 실행할 수 있습니다. 500빌드/월 제한이 있지만, 대부분의 프로젝트에 충분합니다. 대역폭이 많은 프로젝트에 최적입니다.

해설·분석

무료 웹 호스팅 선택에서 가장 중요한 것은 **"프로젝트 유형"과 "트래픽 예상"**입니다. 단순 정적 사이트나 블로그라면 GitHub Pages가 가장 간단합니다. 서버리스 함수가 필요하다면 Netlify나 Vercel이 적합합니다.

Cloudflare Pages는 무제한 대역폭을 제공하여 트래픽이 많은 프로젝트에 최적입니다. Vercel은 Next.js 프로젝트에 최적화되어 있으며, 빌드 시간이 가장 넉넉합니다.

결국 "GitHub 연동" GitHub Pages, "간편 배포" Netlify, "Next.js" Vercel, "무제한 대역폭" Cloudflare Pages 중에서 선택하면 됩니다. 여러 서비스를 병행 사용하는 것도 전략입니다. 예를 들어, 정적 사이트는 GitHub Pages, API는 Vercel에 배포하는 식입니다.
